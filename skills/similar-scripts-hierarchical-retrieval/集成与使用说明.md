# 集成与使用说明

## 一、部署

1. 将整个 `similar-scripts-hierarchical-retrieval/` 目录置于项目的 `.testagent/skills/` 目录下。
2. 为插件或 agent 实际调用脚本所使用的 Python 环境安装 requests 依赖：
   `python -m pip install requests`。
3. 将 `.cache/` 目录加入 `.gitignore`。

## 二、调用方式

在 testagent 流程中通过 skill `similar-scripts-hierarchical-retrieval` 调用，
传入框架脚本路径即可；skill 内部会自动完成检索并生成结果文件
`<框架脚本去扩展名>_explore.json`，无需手动执行命令或进行任何凭据配置。

## 三、可选配置（settings.json）

以下配置项均有默认值，通常无需修改：

- `proxy`：如需通过代理访问，填写 `"http://host:port"`；默认为 `null`（直连）。
- `request.max_workers`：步骤并发数。
- `request.per_step_timeout_sec`：单步骤请求超时时间（秒）。

product_line、pdu_name 及触发点正则默认自动从 TestMate 插件的配置文件读取，
路径为 `%APPDATA%\JetBrains\PyCharm*\options\TestMateCodeElfPersistentState.xml`。
如需手动指定该文件路径，可设置环境变量 `TESTAGENT_XML_PATH`。

如团队公共账号发生变更，请参照 token_manager.py 中的编码方式重新编码，
替换 settings.json 中的 `w3_credential` 字段，并删除 `.cache/token.json`。

## 四、常见问题排查

- **退出码 3（无法识别步骤）**：请检查 TestMate 插件中当前 PDU 的触发点正则配置，
  或确认框架脚本的步骤写法是否符合规范。
- **token 刷新失败（返回 401 / 403）**：请检查 settings.json 中的 `w3_credential`
  及 `token_headers` 内的 `X-HW-ID`、`X-HW-APPKEY` 是否正确；若无法连接，
  请确认网络可访问 `romapi.huawei.com`。
- **检索接口无法连接**：请确认网络可访问 `snapengine.cida...huawei.com`；
  如需通过代理访问，请在 settings.json 中配置 `proxy`。
- **候选结果普遍为空**：通常为相应步骤未达到服务端相似度阈值，属正常现象；
  若全部为空且伴随错误，请检查框架脚本是否包含可供提取的用例编号（如 `CaseID="..."`）。
- **缺少 requests 依赖**：请使用插件或 agent 实际调用的 Python 环境执行
  `python -m pip install requests`。
